paper, not by venue or year.

## File naming

`<firstauthor><year>_<short-title>.pdf`, lowercase, hyphens inside the title slug:

```text
li2025_screenspot-pro.pdf
breiman1984_cart.pdf
```

## Provenance

- **Storing PDFs is an explicit exception to the repository copyright rule** (`docs/references/README.md`, 2026-11-26). The exception covers research papers stored for private reading and citation work. It does not cover redistribution: this repository is not published or shared with the PDFs in place.
- **Open access first.** Prefer arXiv, ACL Anthology, OpenReview, or a publisher open-access edition. A paywalled publisher copy may be stored when it is the version of record and no open edition exists.
- Every file records its licence in `INDEX.md`. A file whose licence forbids redistribution comes out of the repository before it is published or shared.
- This directory holds sources to be read, not evidence the project relies on. A source becomes a citation in `docs/references/` only after it is read and summarized.
